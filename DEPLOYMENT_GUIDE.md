# CryptoRaid Deployment Guide\n\n## 🚀 Deployment Options\n\nChoose your preferred deployment method:\n\n### Option 1: Local/Development Deployment\n### Option 2: Docker Deployment (Recommended)\n### Option 3: Systemd Service Deployment\n### Option 4: Cloud Deployment (AWS Lambda/Heroku)\n\n---\n\n## Option 1: Local Deployment\n\n### Prerequisites\n- Python 3.9+\n- pip package manager\n- Git\n\n### Steps\n\n```bash\n# 1. Clone the repository\ngit clone https://github.com/karandeep2799-source/cryptoraid.git\ncd cryptoraid\n\n# 2. Checkout enhanced branch\ngit checkout enhanced-trading-bots\n\n# 3. Create virtual environment\npython3 -m venv venv\nsource venv/bin/activate  # On Windows: venv\\Scripts\\activate\n\n# 4. Install dependencies\npip install -r requirements.txt\n\n# 5. Setup environment variables\ncp .env.example .env\n# Edit .env with your API keys and preferences\nnano .env\n\n# 6. Create necessary directories\nmkdir -p logs data\n\n# 7. Run the bot\npython main_enhanced.py\n```\n\n### Monitoring\n```bash\n# View logs in real-time\ntail -f logs/cryptoraid.log\n\n# Check performance report\ncat data/performance_report.json | python -m json.tool\n```\n\n---\n\n## Option 2: Docker Deployment (Recommended)\n\n### Prerequisites\n- Docker installed\n- Docker Compose installed\n\n### Steps\n\n```bash\n# 1. Clone repository\ngit clone https://github.com/karandeep2799-source/cryptoraid.git\ncd cryptoraid\n\n# 2. Checkout enhanced branch\ngit checkout enhanced-trading-bots\n\n# 3. Setup environment\ncp .env.example .env\n# Edit .env with your credentials\nnano .env\n\n# 4. Build and start containers\ndocker-compose up -d\n\n# 5. Verify bot is running\ndocker-compose ps\n\n# 6. View logs\ndocker-compose logs -f cryptoraid\n\n# 7. Stop bot (when needed)\ndocker-compose down\n```\n\n### Environment Variables (.env)\n```bash\n# Exchange API Keys\nCOINDCX_API_KEY=your_api_key_here\nCOINDCX_SECRET_KEY=your_secret_key_here\n\n# Notifications\nSLACK_WEBHOOK_URL=https://hooks.slack.com/services/YOUR/WEBHOOK/URL\nTELEGRAM_BOT_TOKEN=your_bot_token\nTELEGRAM_CHAT_ID=your_chat_id\n\n# Configuration\nENVIRONMENT=production\nLOG_LEVEL=INFO\n```\n\n### Docker Compose Benefits\n- Isolated environment\n- Easy to restart/update\n- Volume persistence for logs and data\n- Network isolation\n- Health checks included\n\n---\n\n## Option 3: Systemd Service Deployment (Linux)\n\n### Prerequisites\n- Linux server (Ubuntu/Debian recommended)\n- Python 3.9+\n- sudo access\n\n### Steps\n\n```bash\n# 1. Create dedicated user\nsudo useradd -m -s /bin/bash cryptoraid\n\n# 2. Clone repository to /opt\nsudo git clone https://github.com/karandeep2799-source/cryptoraid.git /opt/cryptoraid\ncd /opt/cryptoraid\nsudo git checkout enhanced-trading-bots\n\n# 3. Set permissions\nsudo chown -R cryptoraid:cryptoraid /opt/cryptoraid\n\n# 4. Install dependencies\nsudo -u cryptoraid python3 -m venv /opt/cryptoraid/venv\nsudo -u cryptoraid /opt/cryptoraid/venv/bin/pip install -r requirements.txt\n\n# 5. Setup environment\nsudo -u cryptoraid cp .env.example .env\nsudo -u cryptoraid nano .env  # Configure credentials\n\n# 6. Copy service file\nsudo cp cryptoraid.service /etc/systemd/system/\n\n# 7. Enable and start service\nsudo systemctl daemon-reload\nsudo systemctl enable cryptoraid\nsudo systemctl start cryptoraid\n\n# 8. Check status\nsudo systemctl status cryptoraid\n```\n\n### Systemd Service Management\n```bash\n# View logs\nsudo journalctl -u cryptoraid -f\n\n# Restart bot\nsudo systemctl restart cryptoraid\n\n# Stop bot\nsudo systemctl stop cryptoraid\n\n# Check if running\nsudo systemctl is-active cryptoraid\n```\n\n---\n\n## Configuration (All Deployments)\n\n### config.ini Settings\n\n```ini\n[main]\n# Trading pairs (comma-separated)\ntarget_symbol = ETH\nsource_symbol = USDT\n\n# Risk Management\nmax_position_size = 1000      # Max USDT per position\nmax_daily_loss_percent = 2    # Stop if daily loss > 2%\nmax_concurrent_trades = 3     # Max open positions\nstop_loss_percent = 5         # Hard stop at -5%\ntrailing_stop_percent = 2     # Trailing stop at 2%\n\n# Trading Parameters\nstrategy = paddle_3way        # Choose: paddle_3way, dca, momentum\nprofit = 1                    # Min profit target (USDT)\nfee = 0.1                     # Exchange fee %\ninterval = 10                 # Check interval (seconds)\ntrend = 30                    # Trend window (seconds)\n\n[notification]\nenable_notifications = true\nnotification_type = webhook   # webhook, telegram, email\nwebhook_url = https://hooks.slack.com/services/YOUR/WEBHOOK/URL\n\n[core]\nversion = 1.0.0\nlogging = INFO\nenvironment = production\n```\n\n---\n\n## Slack Webhook Setup\n\n### Get Webhook URL\n1. Go to https://api.slack.com/apps\n2. Create new app or select existing\n3. Navigate to \"Incoming Webhooks\"\n4. Click \"Add New Webhook to Workspace\"\n5. Select channel\n6. Copy webhook URL\n7. Add to .env: `SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...`\n\n---\n\n## Telegram Bot Setup\n\n### Create Bot\n1. Chat with @BotFather on Telegram\n2. Send `/newbot`\n3. Follow instructions\n4. Copy bot token\n5. Add to .env: `TELEGRAM_BOT_TOKEN=your_bot_token`\n\n### Get Chat ID\n1. Add bot to your Telegram chat\n2. Send a message to the bot\n3. Visit: `https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates`\n4. Find your chat ID\n5. Add to .env: `TELEGRAM_CHAT_ID=your_chat_id`\n\n---\n\n## Monitoring & Maintenance\n\n### Check Bot Health\n```bash\n# View performance report\ncat data/performance_report.json\n\n# Check recent logs\ntail -100 logs/cryptoraid.log\n\n# Monitor in real-time\ntail -f logs/cryptoraid.log | grep -E \"(BUY|SELL|ERROR)\"\n```\n\n### Common Issues\n\n#### Bot not starting?\n```bash\n# Check Python installation\npython3 --version\n\n# Check dependencies\npip list | grep -E \"(requests|art|pandas)\"\n\n# Verify config.ini\ncat config.ini\n```\n\n#### API connection issues?\n```bash\n# Verify API keys\necho $COINDCX_API_KEY\n\n# Test connection\ncurl https://public.coindcx.com/exchange/ticker\n```\n\n#### Docker issues?\n```bash\n# View container logs\ndocker-compose logs cryptoraid\n\n# Rebuild image\ndocker-compose build --no-cache\n\n# Restart containers\ndocker-compose restart\n```\n\n---\n\n## Performance Optimization\n\n### For High-Frequency Trading\n```ini\n[main]\ninterval = 5          #
